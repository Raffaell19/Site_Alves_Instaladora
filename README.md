# Alves Instaladora — Elétrica Residencial de Alto Padrão & Climatização

> Site institucional moderno, responsivo e de alta conversão para a **Alves Instaladora**, atuante no Vale do Paranhana, RS (Nova Hartz, Parobé, Sapiranga, Araricá, Taquara, Igrejinha e região).

---

## ⚡ Tecnologias e Recursos
- **HTML5 Semântico & Schema.org (LocalBusiness / Electrician / HVAC)** para SEO Local e Google 3-Pack.
- **CSS3 Moderno** com variáveis, glassmorphism, suporte completo a mobile e design responsivo (320px a 4K).
- **JavaScript Vanilla** para simulador de orçamento interativo e roteamento dinâmico para WhatsApp.
- **Vercel Edge Ready:** Configurado com `vercel.json` para cache de 1 ano em ativos estáticos e headers de segurança HTTP.

---

## 📂 Estrutura do Projeto
```
Site_Alves_Instaladora/
├── assets/images/       # Imagens de alta definição e fotos de projetos
├── css/
│   └── styles.css       # Folha de estilos responsiva
├── js/
│   ├── config.js        # Configuração de telefones e mensagens
│   └── main.js          # Lógica do simulador, navegação e WhatsApp
├── index.html           # Página principal
├── robots.txt           # Diretrizes para motores de busca
├── sitemap.xml          # Mapa do site para Google Search Console
└── vercel.json          # Configuração de cache e segurança da Vercel
```

## 🌐 Deploy na Vercel
Este repositório está pronto para deploy com 1 clique na [Vercel](https://vercel.com/):
1. Acesse o painel da Vercel.
2. Clique em **Add New... > Project**.
3. Importe o repositório **`Raffaell19/Site_Alves_Instaladora`**.
4. Clique em **Deploy**.
